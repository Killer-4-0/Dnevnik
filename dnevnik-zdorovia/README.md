# Мой дневник здоровья — бэкап кода

Это полная копия кода вашего приложения. Если что-то случится с онлайн-версией — этот архив всегда можно развернуть заново.

## Что нового в этой версии

- **Тренировки по плану с записью подходов**: нажми «Начать тренировку» у плана — и записывай вес и повторы каждого подхода прямо на занятии. Прогресс сохраняется сразу: можно закрыть приложение и продолжить позже (кнопка «Продолжить»).
- **Подсказка с прошлой тренировки**: у каждого упражнения видно, с каким весом и на сколько повторов ты делал его в прошлый раз (и поля веса/повторов заранее заполнены последними значениями).
- **История тренировок**: отдельная панель со всеми прошедшими тренировками — нажми на запись, чтобы раскрыть подходы и веса.
- **Автоподсчёт калорий по БЖУ**: в формах ручного ввода, редактирования и «своих блюд» калории считаются автоматически: 1 г белка = 4 ккал, 1 г углеводов = 4 ккал, 1 г жиров = 9 ккал (галочку можно снять и вписать калории вручную).
- **Блюда из ингредиентов**: собери блюдо (например, пиццу) из ингредиентов с известным КБЖУ — приложение посчитает КБЖУ всей пиццы и на 100 г. Потом просто записывай, сколько грамм съел. Если готовка меняет вес — укажи итоговый вес готового блюда.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Главная страница, разметка всех вкладок |
| `css/style.css` | Оформление (тёмно-синяя тема) |
| `js/db.js` | База ~170 продуктов с КБЖУ, примеры тренировочных планов и меню |
| `js/app.js` | Вся логика приложения |
| `js/storage.js` | Слой сохранения данных (в песочнице предпросмотра — память) |
| `js/config.js` | (Необязательно) конфиг Firebase для всех посетителей |
| `sw.js` | Service worker — офлайн-режим |
| `manifest.webmanifest` + `icons/` | Установка на телефон (PWA) |

## Как запустить где угодно

Это статический сайт — файлы просто раздаются любым хостингом. Варианты:

- Любая папка + любой статический хостинг (GitHub Pages, Netlify, Vercel, обычный хостинг).
- Открыть `index.html` двойным щелчком тоже можно, но установка на телефон и офлайн-режим требуют HTTPS-адрес.

## Настройка функций (кратко)

- **Фото блюда (ИИ)**: Настройки → «Распознавание еды по фото (Gemini)» → вставить ключ с [aistudio.google.com/apikey](https://aistudio.google.com/apikey) (бесплатный тариф).
- **Синхронизация (вход по почте)**: Настройки → «Синхронизация» → «Как настроить»: создать проект на [console.firebase.google.com](https://console.firebase.google.com), включить Authentication → Email/Password и Firestore, вставить `firebaseConfig` в приложение. Подробнее — инструкция прямо в приложении.
- **Данные**: хранятся в браузере устройства (ключ `healthDiary.v2` в localStorage). В Настройках есть экспорт/импорт JSON-файла — делайте резервные копии.
- **Голосовой ввод**: работает в Chrome (Android/компьютер).
- **Штрихкод**: камера на Android (Chrome), иначе — ручной ввод кода.

## Обновление опубликованной версии

Файлы идентичны тем, что работают на сайте. При правках кода поднимайте номер версии кэша в `sw.js` (`CACHE_NAME = "dnevnik-zdorovia-vX"`), чтобы у пользователей обновилось приложение.
